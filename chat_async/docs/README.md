# README.md

## Асинхронное чат-приложение

Этот проект представляет собой асинхронную систему чата, состоящую из сервера и клиента на основе PyQt5. Пользователи могут присоединяться к чат-комнатам, обмениваться сообщениями и использовать встроенные команды. Сервер поддерживает несколько комнат и позволяет добавлять в сообщения эмодзи или выполнять команды вроде `/quit` для выхода.

---

## Функционал

* **Чат-комнаты** : Подключение к комнатам по указанному номеру.
* **Поддержка эмодзи** : Использование команд для добавления эмодзи в сообщения.
* **Команды** :
* `/help` - Показать доступные команды.
* `/listrooms` - Список всех активных комнат и их участников.
* `/quit` - Отключиться от сервера.
* **Кроссплатформенный клиент PyQt5** : Графический интерфейс для удобной работы с чатом.
* **Логирование** : Ошибки и события чата записываются в файл и выводятся в консоль.

## Требования

### Для сервера

* Python 3.8+
* asyncio (встроено)

### Для клиента

* Python 3.8+
* PyQt5
* qasync

### Docker (для развертывания сервера)

* Рекомендуется версия Docker 20.10+.

## Установка и настройка

### Настройка сервера (с Docker)

1. **Создайте Dockerfile** :

   Сохраните следующий код в файл `Dockerfile`:

```Dockerfile
   FROM python:3.10-slim

   WORKDIR /app

   COPY server.py ./

   CMD ["python", "server.py"]
```

1. **Соберите образ Docker** :

   Выполните команду:

```bash
   docker build -t async-chat-server .
```

1. **Запустите сервер** :

   Выполните команду:

```bash
   docker run -d -p 8080:8080 --name chat-server async-chat-server
```

   Теперь сервер слушает соединения на `localhost:8080`.

---

### Настройка клиента

1. **Установите зависимости** :

```bash
   pip install pyqt5 qasync
```

1. **Запустите клиент** :

   Сохраните код `client.py` в файл и выполните:

```bash
   python client.py
```

1. **Необязательно** : Для просмотра логов откройте файл `chat_client.log`.

---

## Инструкция по использованию

### Подключение к серверу

1. Запустите клиентское приложение.
2. Введите ваше **имя** в поле `Enter your name`.
3. Укажите **номер комнаты** (например, `123`) в поле `Enter room number`.
4. Нажмите кнопку  **Connect** .

Если подключение успешно, в журнале чата появится сообщение.

---

### Отправка сообщений

1. Введите сообщение в поле `Type your message here...`.
2. Нажмите **Send** или клавишу `Enter`.

### Команды для эмодзи

Добавляйте эмодзи в сообщения, используя следующие команды:

| Команда эмодзи | Результат    |
| --------------------------- | --------------------- |
| `/happy`                  | `( ͡° ͜ʖ ͡°)` |
| `/angry`                  | `ヽ༼ ಠ益ಠ ༽ﾉ`  |
| `/at-what-cost`           | `ლ(ಠ益ಠლ)`      |
| `/barf`                   | `(´ж｀ς)`        |
| `/sad`                    | `ヽ(´ー｀)ノ`      |

Пример:

```
/happy Привет, всем!
```

Результат:

```
( ͡° ͜ʖ ͡°) Привет, всем!
```

---

### Команды сервера

Команды вводятся в поле чата клиента:

* `/help`: Показать список доступных команд.
* `/listrooms`: Список всех активных комнат и участников.
* `/quit`: Отключиться от сервера.

---

### Логирование

Клиент записывает все действия в файл `chat_client.log`. Это включает:

* Статус подключения.
* Отправленные и полученные сообщения.
* Ошибки в процессе взаимодействия.

Для просмотра логов в реальном времени выполните команду:

```bash
tail -f chat_client.log
```

## Решение проблем

* **Сервер не запускается** :
* Убедитесь, что Docker запущен.
* Проверьте наличие конфликтующих портов на `8080`.
* **Проблемы подключения клиента** :
* Убедитесь, что IP-адрес и порт сервера указаны правильно.
* Проверьте, что сервер запущен.
* **Отсутствуют зависимости** :
* Используйте команду `pip install -r requirements.txt` для установки всех необходимых библиотек.
